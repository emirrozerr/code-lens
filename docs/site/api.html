REST API Reference

The CodeLens REST API is a FastAPI application (app title "CodeLens API", v0.1.0) served on port 8000. Authentication is a JWT carried in an httpOnly cookie named codelens_token. Admin-only routes additionally require role: admin in the token. All examples assume the cookie is sent automatically by the browser (credentials: 'include').

Authentication Model

Login issues a JWT signed with HS256 (settings.jwt_secret_key), expiring after jwt_expiry_minutes (default 1440 = 24 h). Token claims: sub (user id / UUID), email, role ("admin" | "user"), exp.

The token is stored in the httpOnly cookie codelens_token (sameSite=lax; secure controlled by jwt_cookie_secure). The Next.js frontend sets this cookie via its own /api/auth/login route handler, which proxies to the backend's /auth/login.

Two server-side dependencies enforce auth: current_user — decodes the cookie JWT, loads the user from Neo4j, returns 401 if missing / invalid / expired / unknown — and admin_user, which chains on current_user and returns 403 unless role == "admin".

Passwords are hashed with passlib pbkdf2_sha256. Users, repositories, and indexing jobs are all persisted as nodes in Neo4j (:User, :Repository, :IndexingJob).

On startup the API seeds a default admin user admin@codelens.dev if no users exist (password from ADMIN_INITIAL_PASSWORD, default admin123). Change this before any shared deployment.

Repositories /api/repos — Admin only

Repo object shape

{
  "id": "uuid",
  "name": "spring-petclinic",
  "url": "https://github.com/spring-projects/spring-petclinic",
  "paths": [],
  "lastIndexed": "2024-06-01T12:00:00Z",
  "nodeCount": 842,
  "status": "indexed"
}

status is one of: pending | indexing | indexed | failed.

GET /api/repos

Returns an array of all registered repository objects.

POST /api/repos

Register a repository and kick off background indexing. The endpoint creates a :Repository node (status pending), returns immediately, and enqueues a FastAPI BackgroundTask that:

  1. Creates an :IndexingJob node.
  2. Clones the repo (git clone --depth=1 for URLs, or uses a local path).
  3. Runs the Tree-sitter Indexer over the source files.
  4. Loads results into Neo4j (setup_schema + ingest_parse_result).
  5. Runs Louvain clustering + Groq domain naming (non-fatal if it fails).
  6. Marks the job finished and sets the repo to indexed.

Request body

{
  "url": "https://github.com/spring-projects/spring-petclinic",
  "paths": null
}

201 Created — returns the repo object; status will be "pending" at return time.

POST /api/repos/{repo_id}/reindex

Create a new indexing job and re-run the full indexing pipeline in the background.

StatusBody
200Job object (status pending)
404Repo not found

DELETE /api/repos/{repo_id}

Delete a repo and all its associated data: :Domain nodes and all code graph nodes ingested from that repo. Idempotent. Returns 204 with no body.

Opens a text/event-stream (SSE) connection. Emits the full job object as JSON approximately every second until the job's status is no longer running or pending, then closes the stream. Emits { "error": "Job not found" } if the job ID is unknown.

Stats & Graph

GET /api/stats Any JWT

Returns aggregated dashboard counts and Neo4j health. Note: mcpUptime is currently a hardcoded 0.

200 OK

{
  "reposCount": 3,
  "totalNodes": 2541,
  "domainsCount": 18,
  "activeUsers": 4,
  "neo4jStatus": "ok",
  "mcpUptime": 0,
  "lastSuccessfulIndex": "2024-06-01T12:01:30Z"
}

neo4jStatus is "ok" or "down". lastSuccessfulIndex is an ISO timestamp or null.

GET /api/graph Any JWT

Returns the full code graph optimised for force-directed visualisation. Excludes File, ConditionalBranch, ReturnStatement, Unresolved, and admin nodes. Edge types are normalised: extends → inherits; contains / has_branch / returns / IN_DOMAIN → uses. Returns empty arrays on Neo4j error.

200 OK

{
  "nodes": [
    {
      "id": "uuid",
      "label": "PetController",
      "file": "src/main/java/.../PetController.java",
      "signature": "class PetController",
      "domain": "Pet Management",
      "domainId": "uuid",
      "degree": 12
    }
  ],
  "edges": [
    {
      "source": "uuid-a",
      "target": "uuid-b",
      "type": "calls"
    }
  ]
}

Edge type values: calls | imports | inherits | uses.

Chat

POST /chat Any JWT

Streams a chat response over the knowledge graph as Server-Sent Events (SSE). The endpoint optionally fetches domain context, extracts up to three keywords from the message, calls the MCP tools search_nodes and get_code_context to gather graph context, and then streams a Groq completion.

Request body

{
  "message": "Which classes call PetController?",
  "persona": "developer",
  "history": [
    { "role": "user", "content": "Tell me about the domain structure." },
    { "role": "assistant", "content": "The codebase has 4 domains: ..." }
  ],
  "domainId": null
}
FieldTypeDescription
messagestrUser's question
persona"developer" | "product" | "legal"Adjusts the system prompt tone
historyarray of {role, content}Prior conversation turns
domainIdstr | nullPin context to a specific domain

Response — Content-Type: text/event-stream
