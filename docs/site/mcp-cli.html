MCP Tools & CLI

CodeLens exposes its knowledge graph to AI agents through a Model Context Protocol (MCP) server built on FastMCP, and to operators through a Click-based command-line interface. Both read the same Neo4j graph; the data model that both query is documented at the bottom of this page.

MCP Server

Built with FastMCP (from mcp.server.fastmcp import FastMCP; mcp = FastMCP("CodeLens")). Tools are registered with the @mcp.tool() decorator. There is no auth at the MCP layer.

Transports: stdio (default — for local AI clients like Claude Desktop) or SSE (codelens mcp --transport sse --port 8000, for remote/Docker access).

Connection model: each tool call instantiates its own Neo4jClient(), opens a session, runs one Cypher query, formats the rows as plain text, and closes the connection in a finally block. Every tool returns a str (success and error alike).

All 7 tools are read-only — they query the graph but never write to it. Writes happen through the CLI (ingest), the REST API (background indexing), and the watcher.

Tool Reference

search_nodes(keyword: str) -> str

Full-text Lucene search over node name, docstring, signature, and filepath. Returns up to 10 hits ranked by relevance. 

CALL db.index.fulltext.queryNodes("node_search", $keyword) YIELD node, score
RETURN labels(node)[0] AS type, node.name AS name, node.filepath AS filepath,
       node.signature AS signature, node.docstring AS docstring, score
ORDER BY score DESC LIMIT 10

get_code_context(symbol_name: str) -> str

Returns a symbol with its direct callers, callees, and internal conditional branches — multi-hop structural context in one call. 

MATCH (center)
WHERE center.name = $symbol_name AND NOT center:Unresolved
OPTIONAL MATCH (caller)-[:calls]->(center)
OPTIONAL MATCH (center)-[:calls]->(callee)
OPTIONAL MATCH (center)-[:has_branch]->(branch)
RETURN labels(center)[0] AS type, center.filepath AS filepath, center.signature AS signature,
       collect(DISTINCT caller.name) AS callers,
       collect(DISTINCT callee.name) AS callees,
       collect(DISTINCT branch.name) AS branches
LIMIT 1

get_callers(symbol_name: str) -> str

All nodes that call the given symbol — for impact analysis. 

MATCH (caller)-[:calls]->(target)
WHERE target.name = $symbol_name
RETURN labels(caller)[0] AS type, caller.name AS name, caller.filepath AS filepath

get_callees(symbol_name: str) -> str

All internal symbols called by the given symbol (Unresolved sources filtered out). 

MATCH (source)-[:calls]->(callee)
WHERE source.name = $symbol_name AND NOT source:Unresolved
RETURN labels(callee)[0] AS type, callee.name AS name

get_domains() -> str

Lists all discovered Domain nodes with member counts and summaries, largest first. 

MATCH (d:Domain)
OPTIONAL MATCH (n)-[:IN_DOMAIN]->(d)
RETURN d.name AS name, d.summary AS summary, count(n) AS member_count
ORDER BY member_count DESC

get_domain(symbol_name: str) -> str

Given a symbol, returns the domain it belongs to, with the domain summary and all members. 

MATCH (n)-[:IN_DOMAIN]->(d:Domain)
WHERE n.name = $symbol_name
OPTIONAL MATCH (member)-[:IN_DOMAIN]->(d)
RETURN d.name AS domain_name, d.summary AS summary, collect(DISTINCT member) AS members
LIMIT 1

get_domain_content(domain_name: str) -> str

Given a domain name, returns its summary and all member nodes (the inverse of get_domain). 

MATCH (d:Domain {name: $domain_name})
OPTIONAL MATCH (n)-[:IN_DOMAIN]->(d)
RETURN d.summary AS summary, collect(n) AS members

Command-Line Interface

The codelens CLI (Click) is the operator entry point. All commands read configuration from .env via the Settings singleton.

Command Description
codelens index <repo> [--stats] [--output FILE] Parse a repo in memory only (no Neo4j). Prints a node/edge summary; --stats adds detail; --output writes the ParseResult as JSON.
codelens ingest <repo> [--clear] [--cluster] Parse a repo and load it into Neo4j. --clear wipes the graph first (preserving admin nodes); --cluster runs domain detection after loading.
codelens watch <repo> Run the watchdog daemon: full index once, then incrementally re-index changed files into Neo4j until interrupted.
codelens mcp [--transport stdio|sse] [--host H] [--port P] Start the MCP server. stdio by default; SSE for remote access.
codelens api [--host H] [--port P] Start the FastAPI REST server (Uvicorn).

Index Spring PetClinic into Neo4j with domain clustering

# start Neo4j first
docker compose up -d neo4j
# parse + load + cluster
codelens ingest ./spring-petclinic --clear --cluster

Expose the graph to an AI agent over stdio

codelens mcp
# or for remote access over SSE
codelens mcp --transport sse --port 8000

Data Model

Everything above queries one property graph in Neo4j. Nodes are uniquely keyed by a uid (format <filepath>:<qualified_name>). The schema (uniqueness constraints + a node_search fulltext index) is created by Neo4jClient.setup_schema(). 

graph LR
    File -->|contains| Class
    File -->|contains| Interface
    File -->|imports| File
    Class -->|contains| Function
    Class -->|contains| Constructor
    Class -->|extends| Class
    Class -->|implements| Interface
    Function -->|calls| Function
    Function -->|has_branch| ConditionalBranch
    Function -->|returns| ReturnStatement
    Function -->|IN_DOMAIN| Domain
    Class -->|IN_DOMAIN| Domain
Core node labels and relationship types. Domain nodes are added by the clustering step; everything else is emitted by the parsers.

Node Types

Label Meaning
File A parsed source file
Package A Java package grouping
Class A class declaration
Interface An interface declaration
Function A method or standalone function
Constructor A constructor (Java) or __init__ (Python)
ConditionalBranch An if/switch/for/while/match branch inside a function
ReturnStatement A return statement
Domain A discovered domain (added by clustering)
Unresolved A call target that could not be resolved to a known symbol

Relationship Types

Type From → To
contains File→Class, Class→Function, etc.
calls Function→Function
imports File→File
implements Class→Interface
extends Class→Class (or Python subclass)
has_branch Function→ConditionalBranch
returns Function→ReturnStatement
IN_DOMAIN Class/Function → Domain

Key Node Properties

Property Description
uid Globally unique key, <filepath>:<qualified_name>
name Simple symbol name (used by MCP search/lookups)
qualified_name e.g. ClassName.methodName
node_type One of the labels above
filepath Path relative to repo root
start_line / end_line Source span
signature Function/constructor signature (when available)
docstring Docstring/Javadoc (when available)
file_hash SHA-256 of the source at index time
